# Random Forest

Implementation of Random Forest Classification using Scikit-learn.

---

## Objective

This experiment demonstrates how Random Forest can be used for classification tasks using ensemble machine learning techniques.

---

## Technologies Used

- Python
- Matplotlib
- Scikit-learn

---

## Features

- Iris dataset classification
- Train-test data splitting
- Random Forest model training
- Prediction generation
- Accuracy evaluation
- Classification report generation
- Confusion matrix visualization

---

## Output

The model classifies Iris flower species and visualizes the confusion matrix for prediction analysis.
