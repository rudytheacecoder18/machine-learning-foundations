# Naive Bayes

Implementation of Gaussian Naive Bayes Classification using Scikit-learn.

---

## Objective

This experiment demonstrates how Gaussian Naive Bayes can be used for probabilistic classification tasks using supervised machine learning.

---

## Technologies Used

- Python
- Matplotlib
- Scikit-learn

---

## Features

- Wine dataset classification
- Train-test data splitting
- Gaussian Naive Bayes model training
- Prediction generation
- Accuracy evaluation
- Classification report generation
- Confusion matrix visualization

---

## Output

The model classifies wine categories and visualizes the confusion matrix for prediction analysis.
