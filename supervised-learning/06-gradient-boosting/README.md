# Gradient Boosting

Implementation of Gradient Boosting Classification using Scikit-learn.

---

## Objective

This experiment demonstrates how Gradient Boosting can be used for classification tasks using ensemble machine learning techniques.

---

## Technologies Used

- Python
- Matplotlib
- Scikit-learn

---

## Features

- Iris dataset classification
- Train-test data splitting
- Gradient Boosting model training
- Prediction generation
- Accuracy evaluation
- Confusion matrix visualization

---

## Output

The model classifies Iris flower species and visualizes the confusion matrix for prediction analysis.
