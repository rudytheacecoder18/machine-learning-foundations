# Decision Trees

Implementation of Decision Tree Classification using Scikit-learn.

---

## Objective

This experiment demonstrates how Decision Trees can be used for classification tasks using supervised machine learning.

---

## Technologies Used

- Python
- Matplotlib
- Scikit-learn

---

## Features

- Iris dataset classification
- Train-test data splitting
- Decision Tree model training
- Prediction generation
- Accuracy evaluation
- Decision Tree visualization

---

## Output

The model classifies Iris flower species and visualizes the decision tree structure.
