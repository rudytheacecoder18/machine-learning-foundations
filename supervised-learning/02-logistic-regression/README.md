# Logistic Regression

Implementation of Logistic Regression using Scikit-learn.

---

## Objective

This experiment demonstrates how Logistic Regression can be used for binary classification problems using supervised machine learning.

---

## Technologies Used

- Python
- NumPy
- Matplotlib
- Scikit-learn

---

## Features

- Synthetic classification dataset generation
- Train-test data splitting
- Logistic Regression model training
- Binary classification
- Decision boundary visualization
- Accuracy evaluation

---

## Output

The model classifies data points and visualizes the decision boundary between classes.
