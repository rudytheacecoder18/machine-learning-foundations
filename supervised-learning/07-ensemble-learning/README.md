# Ensemble Learning

Implementation of Ensemble Learning using Voting Classifier in Scikit-learn.

---

## Objective

This experiment demonstrates how multiple machine learning models can be combined using ensemble learning techniques to improve classification performance.

---

## Technologies Used

- Python
- Matplotlib
- Scikit-learn

---

## Features

- Wine dataset classification
- Train-test data splitting
- Multiple classifier integration
- Voting Classifier implementation
- Prediction generation
- Accuracy evaluation
- Classification report generation
- Confusion matrix visualization

---

## Output

The ensemble model classifies wine categories and visualizes the confusion matrix for prediction analysis.
