# Linear Regression

Implementation of Linear Regression using Scikit-learn.

---

## Objective

This experiment demonstrates how Linear Regression can be used to predict continuous numerical values using supervised machine learning.

---

## Technologies Used

- Python
- NumPy
- Matplotlib
- Scikit-learn

---

## Features

- Synthetic dataset generation
- Train-test data splitting
- Linear Regression model training
- Prediction generation
- Mean Squared Error evaluation
- Regression line visualization

---

## Output

The model predicts target values and visualizes the fitted regression line along with actual test data points.
