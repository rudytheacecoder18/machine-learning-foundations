# Principal Component Analysis (PCA)

Implementation of PCA using Scikit-learn.

---

## Objective

This experiment demonstrates how Principal Component Analysis (PCA) can reduce dimensionality while preserving important information in the dataset.

---

## Technologies Used

- Python
- NumPy
- Matplotlib
- Scikit-learn

---

## Features

- Correlated dataset generation
- PCA transformation
- Dimensionality reduction
- Variance analysis
- Data visualization

---

## Output

The program visualizes:
- Original correlated dataset
- PCA-transformed dataset
- Explained variance ratio
