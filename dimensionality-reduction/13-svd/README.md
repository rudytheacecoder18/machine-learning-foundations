# Singular Value Decomposition (SVD)

Implementation of Singular Value Decomposition using NumPy.

---

## Objective

This experiment demonstrates how Singular Value Decomposition (SVD) can decompose a matrix into its constituent components for dimensionality reduction and matrix analysis.

---

## Technologies Used

- Python
- NumPy
- Matplotlib

---

## Features

- Random matrix generation
- Matrix decomposition using SVD
- Matrix reconstruction
- Singular value analysis
- Visualization of singular values

---

## Output

The program displays:
- Original matrix
- U matrix
- Singular values
- Vt matrix
- Reconstructed matrix
- Singular value graph
