# Linear Discriminant Analysis (LDA)

Implementation of Linear Discriminant Analysis using Scikit-learn.

---

## Objective

This experiment demonstrates how Linear Discriminant Analysis (LDA) can reduce dimensionality while maximizing class separability.

---

## Technologies Used

- Python
- Matplotlib
- Scikit-learn

---

## Features

- Wine dataset classification
- Dimensionality reduction
- LDA transformation
- KNN classification
- Accuracy evaluation
- Reduced-dimensionality visualization

---

## Output

The program visualizes:
- LDA-transformed dataset
- Reduced feature representation
- Class separation in lower dimensions
