# Hypothesis Testing

Implementation of Hypothesis Testing using SciPy.

---

## Objective

This experiment demonstrates how hypothesis testing can determine whether sample data significantly differs from a hypothesized population mean.

---

## Technologies Used

- Python
- NumPy
- Matplotlib
- SciPy

---

## Features

- Random sample generation
- One-sample t-test
- Statistical significance testing
- P-value calculation
- Hypothesis decision analysis
- Histogram visualization

---

## Output

The program visualizes:
- Sample distribution
- Sample mean
- Population mean
- Statistical test results
