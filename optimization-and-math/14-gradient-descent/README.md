# Gradient Descent

Implementation of Gradient Descent Optimization using NumPy.

---

## Objective

This experiment demonstrates how Gradient Descent can optimize parameters in Linear Regression by minimizing the cost function.

---

## Technologies Used

- Python
- NumPy
- Matplotlib

---

## Features

- Synthetic dataset generation
- Linear Regression optimization
- Cost function minimization
- Iterative parameter updates
- Cost reduction visualization

---

## Output

The program visualizes:
- Cost function reduction over iterations
- Optimized model parameters
