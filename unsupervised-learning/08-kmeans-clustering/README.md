# K-Means Clustering

Implementation of K-Means Clustering using Scikit-learn.

---

## Objective

This experiment demonstrates how K-Means Clustering can be used to group similar data points into clusters using unsupervised machine learning.

---

## Technologies Used

- Python
- Matplotlib
- Scikit-learn

---

## Features

- Synthetic dataset generation
- Elbow method implementation
- Optimal cluster selection
- K-Means clustering
- Cluster centroid visualization
- Data point grouping

---

## Output

The program visualizes:
- Elbow Method graph
- Final K-Means clustering result
- Cluster centroids

---
