# DBSCAN Clustering

Implementation of DBSCAN Clustering using Scikit-learn.

---

## Objective

This experiment demonstrates how DBSCAN clustering can identify clusters and detect outliers using density-based unsupervised machine learning.

---

## Technologies Used

- Python
- NumPy
- Matplotlib
- Scikit-learn

---

## Features

- Synthetic dataset generation
- Density-based clustering
- Outlier detection
- Cluster identification
- Core and boundary point visualization
- Noise point analysis

---

## Output

The program visualizes:
- Cluster formation
- Core samples
- Boundary samples
- Noise points (outliers)
