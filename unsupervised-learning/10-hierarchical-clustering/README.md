# Hierarchical Clustering

Implementation of Hierarchical Agglomerative Clustering using SciPy and Scikit-learn.

---

## Objective

This experiment demonstrates how hierarchical clustering can group similar data points into clusters using agglomerative clustering techniques.

---

## Technologies Used

- Python
- Matplotlib
- SciPy
- Scikit-learn

---

## Features

- Synthetic dataset generation
- Agglomerative clustering
- Dendrogram visualization
- Cluster hierarchy analysis
- Euclidean distance measurement

---

## Output

The program visualizes a dendrogram representing the hierarchical relationships between clustered data points.
